เว็บไซต์ SUPERX AI  (ไทย / 中文 / English)
=============================================

1) เปิดดูเว็บ
   ดับเบิลคลิกไฟล์ index.html  → เปิดใน Chrome ได้ทันที กดเมนูไปทุกหน้าได้
   ปุ่มเปลี่ยนภาษาอยู่มุมขวาบน (ไทย / 中文 / EN) เว็บจะจำภาษาที่เลือกไว้

2) หน้าทั้งหมด (แยกไฟล์ชัดเจน)
   index.html        หน้าแรก (首页)
   products.html     ผลิตภัณฑ์ทั้งหมด + ตารางเปรียบเทียบ + Z5 Multi-Locker + Z20 (产品中心)
   z5.html           RoboVan Z5 / Z5 Plus
   z10.html          RoboVan Z10
   cold-chain.html   รถห้องเย็น Z5 / Z10 Cold-Chain (冷链车型)
   education.html    รถไร้คนขับเพื่อการศึกษา (教育无人车)
   security.html     รถตีนตะขาบ + หุ่นยนต์ความปลอดภัยและงานพิเศษ (履带型无人车 / 安防与特种机器人)
   ai-agent.html     AI Agent · Qubby AI
   about.html        เกี่ยวกับ SuperX + พันธมิตร (关于 SuperX / 合作伙伴)
   cases.html        ผลงานและโครงการ (项目案例)
   news.html         ข่าวสาร (新闻与动态)
   contact.html      ติดต่อเรา + แบบฟอร์มนัดสาธิต (联系我们 / 预约演示)
   404.html          หน้า "ไม่พบหน้านี้" เมื่อมีคนพิมพ์ลิงก์ผิด

   รูปอยู่ใน assets/img   วิดีโออยู่ใน assets/video   โบรชัวร์ PDF อยู่ใน assets/docs
   จะเปลี่ยนรูป: เอารูปใหม่มาวางแทน โดยตั้งชื่อไฟล์ให้เหมือนเดิม

   ไฟล์ระบบ (ห้ามลบ ห้ามเปลี่ยนชื่อ)
   _worker.js        ตัวส่งข้อมูลจากแบบฟอร์มเข้ากลุ่ม Lark ทีมขาย
   _routes.json      บอก Cloudflare ว่าเรียกตัวส่งข้อมูลเฉพาะตอนส่งฟอร์ม

3) เอาเว็บขึ้นออนไลน์ฟรี (Cloudflare Pages)
   1. เข้า https://dash.cloudflare.com แล้วสมัครหรือล็อกอิน (ใช้อีเมลบริษัท)
   2. เมนู Workers & Pages → Create → เลือก Pages → Upload assets (อัปโหลดแบบลากวาง)
   3. ตั้งชื่อโปรเจกต์ เช่น superx-ai → ลากโฟลเดอร์ SuperX-Website ทั้งโฟลเดอร์ไปวาง → Deploy
      จะได้ลิงก์เว็บ เช่น https://superx-ai.pages.dev
   4. ใช้ชื่อ www.super-x.tech: ในโปรเจกต์ → Custom domains → Set up a custom domain
   5. แก้ไฟล์แล้วอยากอัปเดตเว็บ: เข้าโปรเจกต์ → Create deployment → ลากโฟลเดอร์วางใหม่
   ถ้าเปิดเว็บจากไฟล์ในเครื่อง แบบฟอร์มจะให้คัดลอกข้อความไปส่งทางอีเมลแทน (ส่งเองอัตโนมัติเฉพาะบนเว็บจริง)

4) แบบฟอร์มนัดสาธิต → การ์ดแจ้งเข้ากลุ่ม Lark ทีมขายทันที
   ก. สร้างบอทในกลุ่ม Lark (ทำในแอป Lark บนคอมพิวเตอร์ เพราะแอปมือถือเพิ่มบอทแบบนี้ไม่ได้)
      1. เปิดกลุ่มทีมขาย → ปุ่ม ⋯ มุมขวาบน → Settings (การตั้งค่า) → Bots (บอท) → Add Bot (เพิ่มบอท)
      2. เลือก Custom Bot → ตั้งชื่อ เช่น SuperX Website → Add
      3. คัดลอก Webhook URL (ขึ้นต้นด้วย https://open.larksuite.com/open-apis/bot/v2/hook/)
         ลิงก์นี้คือกุญแจ ใครมีลิงก์ก็ส่งข้อความเข้ากลุ่มได้ อย่าโพสต์ในแชทหรือส่งให้ใคร
      4. (แนะนำ) เปิด Signature verification แล้วคัดลอกรหัส (Key) เก็บไว้ด้วย
   ข. ใส่ค่าใน Cloudflare (ทำเองเท่านั้น)
      1. โปรเจกต์ superx-ai → Settings → Variables and Secrets → Add
      2. ชื่อ LARK_WEBHOOK_URL  ชนิด Secret  ค่า = Webhook URL จากข้อ ก.3
      3. ถ้าเปิด Signature ในข้อ ก.4: ชื่อ LARK_WEBHOOK_SECRET  ชนิด Secret  ค่า = รหัส Key
      4. (ไม่บังคับ) ชื่อ LARK_CRM_URL ค่า = ลิงก์ตาราง SALE CRM ที่คัดลอกจากเบราว์เซอร์
         การ์ดจะมีปุ่ม "เปิด SALE CRM"
      5. กด Save แล้วอัปโหลดเว็บใหม่อีกครั้ง (Create deployment) ค่าที่ใส่จะเริ่มทำงาน
   ค. ทดสอบ: เปิดหน้า ติดต่อเรา บนเว็บจริง กรอกฟอร์มแล้วกดส่ง การ์ดจะเด้งในกลุ่มภายในไม่กี่วินาที
      - สีหัวการ์ด: น้ำเงิน = นัดสาธิต / ส้ม = ขอราคา ซื้อ หรือเช่า / เขียวอมฟ้า = พันธมิตร ตัวแทนจำหน่าย
        / ฟ้าอ่อน = เรื่องอื่น / เทา = อาจเป็นสแปม
      - การ์ดบอกภาษาที่ลูกค้าใช้ และหน้าที่ลูกค้ากดมา (เช่น /z10) ช่วยให้เซลล์รู้ว่าสนใจรุ่นไหน
      - ถ้าส่งเข้า Lark ไม่ได้ ลูกค้าจะเห็นปุ่มคัดลอกข้อความ/ส่งอีเมลแทน ข้อมูลลูกค้าไม่หาย
      - ถ้าไม่มีการ์ดเด้ง: ดูว่าใส่ LARK_WEBHOOK_URL ถูกต้อง และอัปโหลดเว็บใหม่หลังใส่ค่าแล้ว
   ง. (เปิดภายหลังได้) บันทึกลูกค้าลงตาราง SALE CRM อัตโนมัติด้วย
      ต้องมีแอป Lark ที่มีสิทธิ์แก้ไขตาราง และเพิ่มแอปนั้นเข้าไปในไฟล์ Base ก่อน
      แล้วใส่ค่า LARK_APP_ID, LARK_APP_SECRET, LARK_BASE_APP_TOKEN, LARK_BASE_TABLE_ID ใน Cloudflare
      ระบบจะเติม ชื่อลูกค้า (บริษัท) ผู้ติดต่อ เบอร์โทร อีเมล และวิธีจัดซื้อ (ซื้อขาด/เช่า) ให้
      ส่วนนี้ให้ Claude ช่วยตั้งค่าได้

   - ชื่อโครงการ/องค์กร (T-CAV, WHA ESIE 1, ไปรษณีย์ไทย, Singapore Post, POS Malaysia, ฟิลิปปินส์) มาจาก Company Profile
     ควรยืนยันว่าเผยแพร่ชื่อบนเว็บได้
   - ตัวเลข 30,000+ คัน / 150M+ km / 27 ตัน และเป้า 10,000 คันภายในปี 2030 มาจาก Company Profile ควรเช็กว่ายังเป็นตัวเลขล่าสุด
