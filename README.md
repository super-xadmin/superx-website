# เว็บไซต์ SUPERX AI — คู่มือแก้ไขเนื้อหาผ่านหลังบ้าน

เนื้อหาทุกอย่างบนเว็บ (ข้อความ 3 ภาษา รูป วิดีโอ PDF สเปกรถ ข่าว ผลงาน เมนู ข้อมูลติดต่อ แบบฟอร์ม) แก้ได้ที่หลังบ้าน **Pages CMS** โดยไม่ต้องเขียนโค้ด

**ขั้นตอนการทำงาน:** แก้ที่หลังบ้าน → กด **Save** → ระบบบันทึกเข้า GitHub → Cloudflare สร้างเว็บใหม่และขึ้นออนไลน์เองภายในประมาณ 1–2 นาที

## 1. เข้าหลังบ้าน

1. เปิด <https://app.pagescms.org>
2. เข้าสู่ระบบด้วยบัญชี GitHub ที่ดูแลเว็บ (super-xadmin)
3. เลือก **superx-website** แล้วเลือก branch **main**

> เชิญเพื่อนร่วมทีมมาช่วยแก้ได้ทางอีเมล (ไม่ต้องมีบัญชี GitHub) ที่หัวข้อ Collaborators ใน Pages CMS ผู้ที่ถูกเชิญแก้เนื้อหาและรูปได้ แต่แก้การตั้งค่าระบบไม่ได้

## 2. เมนูในหลังบ้าน

| เมนู | ใช้ทำอะไร |
|---|---|
| 📰 **ข่าวสาร** | เพิ่ม แก้ ซ่อน หรือลบข่าว |
| 📣 **ป๊อปอัพ / โปรโมชั่น** | ป๊อปอัพที่ขึ้นเมื่อลูกค้าเข้าเว็บ: โฆษณารถ ขั้นตอนเริ่มใช้งาน หรือโปรโมชั่น (ดูข้อ 6.7) |
| 💬 **แชทบนเว็บ** | ข้อความในกล่องแชท เวลาทำการ และปุ่มเปิด/ปิดแชท (ดูข้อ 8.1) |
| 📄 **หน้าเว็บ** | ทุกหน้าของเว็บ แต่ละหน้าแบ่งเป็นหัวข้อ เรียง 1, 2, 3… ตามที่เห็นบนเว็บจากบนลงล่าง |
| 📁 **ผลงาน / โครงการ** | โครงการในหน้า "ผลงาน" (1 โครงการ = 1 รายการ) |
| 🚐 **ข้อมูลรถแต่ละรุ่น** | ชื่อรุ่น รูปรถ สเปก ตัวเลขบนการ์ด ไฟล์ PDF ใช้ร่วมกันทุกหน้า แก้ที่เดียวเปลี่ยนทุกที่ |
| ⚙️ **ตั้งค่าทั้งเว็บไซต์** | ข้อมูลบริษัท (เบอร์ อีเมล ที่อยู่ โซเชียล โลโก้) เมนูด้านบน/ล่าง ข้อความปุ่มที่ใช้หลายหน้า และหัวแถวตารางสเปก |

ในทุกหน้าของเมนู 📄 จะมีหัวข้อ **"ตั้งค่าหน้า"** สำหรับชื่อหน้า (ที่แสดงบนแท็บและ Google) และแถบสีน้ำเงินท้ายหน้า

## 3. วิธีพิมพ์ข้อความ

- ข้อความทุกช่องมี 3 ภาษา: **· ไทย**, **· 中文**, **· English**
- ถ้าเว้นช่องจีนหรืออังกฤษว่าง เว็บจะแสดงภาษาอังกฤษ (หรือไทย) แทนให้อัตโนมัติ ไม่มีช่องว่างโผล่
- **ตัวหนา / คำเน้น:** พิมพ์ `**ข้อความ**` (ดอกจัน 2 ตัวหน้าและหลัง) ในย่อหน้าจะเป็นตัวหนา ส่วนในหัวข้อใหญ่จะเป็น**สีฟ้า**
- **ขึ้นบรรทัดใหม่:** กด Enter ในช่องข้อความแบบยาว
- **ลิงก์ในเว็บ:** ใส่ชื่อหน้า เช่น `contact.html`, `products.html#z20`, `contact.html?topic=demo`
- **ลิงก์ภายนอก:** ขึ้นต้นด้วย `https://`
- **รายการ (การ์ด ขั้นตอน รูป ฯลฯ):** เพิ่ม ลบ หรือสลับลำดับได้ในหลังบ้าน

## 4. รูปภาพ วิดีโอ และ PDF

- อัปโหลดได้ในช่องรูปหรือไฟล์ของแต่ละหัวข้อ หรือที่เมนู Media
- **รูป:** .webp หรือ .jpg ความกว้างประมาณ 1600–2000 px ขนาดไม่เกินประมาณ 1 MB ต่อรูป (เว็บจะโหลดเร็ว)
- **วิดีโอ:** .mp4 **ไม่เกิน 25 MB** (เป็นข้อจำกัดของ Cloudflare ไฟล์ที่ใหญ่กว่านี้จะไม่ถูกนำขึ้นเว็บ)
- **PDF:** ไม่เกิน 25 MB ขนาดไฟล์ที่แสดงบนปุ่มดาวน์โหลดคำนวณให้เอง
- ตั้งชื่อไฟล์เป็นภาษาอังกฤษ ไม่มีเว้นวรรค จะดีที่สุด เช่น `z10-factory-01.webp`
- ช่อง **"คำอธิบายรูป (alt)"** ใส่ภาษาอังกฤษสั้นๆ ว่าในรูปมีอะไร (ช่วยเรื่อง Google)

## 5. เพิ่มข่าวใหม่

1. เมนู 📰 **ข่าวสาร** → กดปุ่มเพิ่มรายการใหม่
2. กรอก **หัวข้อข่าว**, **วันที่ของข่าว**, **แสดงวันที่แบบ** (วัน เดือน ปี / เดือน ปี / ปีอย่างเดียว), **ประเภทข่าว**, **สรุปข่าวสั้นๆ** และ **รูปหลัก**
3. ถ้าต้องการให้มี**หน้าอ่านข่าวฉบับเต็ม** ให้พิมพ์ในช่อง **"เนื้อหาข่าวฉบับเต็ม"** (ใส่หัวข้อย่อย ตัวหนา รายการ ลิงก์ และรูปได้) เว็บจะสร้างหน้าใหม่ให้ และในรายการข่าวจะมีปุ่ม "อ่านข่าวฉบับเต็ม" ใส่รูปเพิ่มเติมหรือวิดีโอได้ด้วย
4. ถ้าเป็นข่าวที่สื่อลง ให้ใส่ **ลิงก์ข่าวต้นฉบับ** และ **ชื่อแหล่งข่าว**
5. ติ๊ก **"ข่าวเด่น"** ถ้าต้องการให้แสดงใหญ่ด้านบนสุดของหน้าข่าว (ถ้าติ๊กไว้หลายข่าว จะแสดงข่าวที่วันที่ใหม่ที่สุด)
6. กด **Save** แล้วรอ 1–2 นาที จากนั้นเปิดเว็บแล้วกด Refresh

ข่าวเรียงจากวันที่ใหม่ไปเก่าอัตโนมัติ · ถ้ายังไม่อยากให้ข่าวขึ้นเว็บ ให้ติ๊ก **"ซ่อนข่าวนี้"**

## 6. เพิ่มผลงาน / โครงการ

เมนู 📁 **ผลงาน / โครงการ** → เพิ่มรายการใหม่

- **รหัสโครงการ:** ภาษาอังกฤษตัวเล็ก ไม่เว้นวรรค เช่น `tpi-polene` ใช้ลิงก์ตรงไปที่โครงการได้ เช่น `cases.html#tpi-polene`

- **ลำดับการแสดง:** เลขน้อยแสดงก่อน
- รูปแรกในรายการรูปจะแสดงใหญ่ · มีวิดีโอได้ 1 คลิปต่อโครงการ

## 6.1 เพิ่มหน้าธุรกิจ / โซลูชันใหม่ (ไม่ต้องรอผู้ดูแล)

เมนู 📦 **ธุรกิจ / โซลูชัน** → เพิ่มรายการใหม่ = ได้หน้าเว็บใหม่ 1 หน้า

- **ชื่อหน้า:** ภาษาอังกฤษตัวเล็ก ไม่เว้นวรรค เช่น `ai-agent-pro` → หน้าเว็บจะเป็น `ai-agent-pro.html` (ตั้งครั้งเดียว)
- **แสดงในเมนูด้านบน:** เลือกได้ว่าอยู่ใต้ "โซลูชันอื่น" (ค่าเริ่มต้น) "RoboVan" หรือ "เกี่ยวกับ SuperX" หรือไม่แสดง

- ถ้าไม่ใส่ภาพหลัก ด้านบนจะเป็นพื้นน้ำเงินเข้มมีแสงเคลื่อนไหวแทน

  - ⚠️ หน้านี้**ปิดไว้ก่อน** ใส่ตัวเลขจริงในหัวข้อ 3 แล้วติ๊ก **"เปิดใช้งานหน้านี้"** ในหัวข้อ "ตั้งค่าหน้า" จากนั้นหน้าและเมนูจะขึ้นเว็บเอง

## 6.3 ภาพหมุนรถ 360°

🚐 **ข้อมูลรถแต่ละรุ่น** → เลือกรุ่น → ช่อง **"ภาพหมุนรอบคัน 360°"** เลือกรูป 24–36 รูป (ถ่ายรอบคันทุก 10–15 องศา ขนาดรูปเท่ากัน เรียงตามมุม)
หรือใส่ **ไฟล์ 3D (.glb)** ถ้ามีจาก Zelostech (ไฟล์ใหญ่ให้วางในโฟลเดอร์ `assets/3d` ผ่าน GitHub Desktop แล้วกด Select) หน้ารุ่นรถจะลากหมุนดูได้เอง

## 6.5 วิดีโอพื้นหลังของแต่ละส่วน 🎬

ทุกหัวข้อของทุกหน้า (ยกเว้นวิดีโอด้านบนสุดของหน้าแรก ที่มีช่องวิดีโอของตัวเองอยู่แล้ว) มีกลุ่มช่อง **"🎬 วิดีโอพื้นหลังของส่วนนี้"** อยู่ท้ายฟอร์ม
- **วิดีโอ:** MP4 สั้นๆ ไม่มีเสียง เล่นวนอัตโนมัติ แนะนำยาว 10–20 วินาที ขนาด 1280×720 ไฟล์ไม่เกิน 10 MB
- **ภาพนิ่ง:** แสดงระหว่างรอวิดีโอโหลด (ถ้าใส่แค่ภาพโดยไม่ใส่วิดีโอ จะได้ภาพนิ่งเป็นพื้นหลังแทน)
- **ความเข้มของสีเข้มที่ทับวิดีโอ:** อ่อน / ปานกลาง / เข้ม ถ้าอ่านตัวหนังสือยากให้เลือก "เข้ม"
- ใส่แล้วส่วนนั้นจะเปลี่ยนเป็นพื้นเข้ม ตัวหนังสือสีขาวให้อัตโนมัติ · ลบไฟล์ออก = กลับเป็นแบบเดิม
- แถบปิดท้ายของแต่ละหน้า ตั้งได้ที่ **ตั้งค่าหน้า** → "แถบปิดท้ายหน้า: 🎬 วิดีโอพื้นหลัง"
- ไฟล์ใหญ่กว่าประมาณ 4 MB อัปผ่านหลังบ้านไม่ได้ (ขึ้น Error 413) ให้วางไฟล์ในโฟลเดอร์ `assets/video` ผ่าน GitHub Desktop → Commit → Push แล้วกลับมากดเลือกไฟล์ในช่องนี้
- เว็บจะโหลดวิดีโอเฉพาะตอนเลื่อนมาถึงส่วนนั้น และหยุดเล่นเมื่อเลื่อนผ่านไป จึงไม่ทำให้หน้าเว็บช้า แต่ไม่ควรใส่วิดีโอติดกันทุกส่วน ใส่ 1–3 ส่วนต่อหน้าจะดูดีที่สุด

## 6.6 โครงเว็บ: ธุรกิจหลัก (RoboVan) มาก่อน

เว็บจัดลำดับให้ลูกค้าเห็นทันทีว่าธุรกิจหลักคือ**รถขนส่งไร้คนขับ RoboVan** ส่วนการศึกษา หุ่นยนต์ความปลอดภัย และ AI Agent เป็น**โซลูชันอื่น**

- **เมนูด้านบน 3 กลุ่ม:** ⚙️ → **เมนูด้านบนและด้านล่างเว็บ** → กลุ่มที่ 1 RoboVan · กลุ่มที่ 2 โซลูชันอื่น · กลุ่มที่ 3 เกี่ยวกับ (ลบทุกรายการของกลุ่มไหน กลุ่มนั้นจะไม่แสดง) ด้านล่างเว็บมีคอลัมน์ RoboVan และโซลูชันอื่นแยกกันเช่นกัน
- **หน้าแรก เรียงจากบนลงล่าง:** 1. ภาพวิดีโอ (บอกว่าเราขายอะไร ให้ใคร) → 2. แถบโครงการนำร่องและพันธมิตร → 3. เราทำอะไร → 4. รุ่นรถ RoboVan → 5. ขั้นตอนเริ่มใช้งาน 1-2-3 → 6. งานที่ใช้ RoboVan ได้ → 7. ผลงาน → 8. แอปควบคุมฝูงรถ → 9. โซลูชันอื่น
- **2. แถบโครงการนำร่องและพันธมิตร:** แต่ละรายการมีชื่อ คำอธิบายเล็ก และลิงก์ (เช่น `cases.html#wha`) ถ้าใส่โลโก้จะแสดงโลโก้แทนชื่อ ลบทุกรายการ = ไม่แสดงแถบนี้
- **หน้า RoboVan ทุกรุ่น** (`products.html`): การ์ดรถและตารางเปรียบเทียบ → รุ่นอื่น → ซื้อหรือเช่า → ชุดระบบ L4 → โซลูชันอื่น (ลิงก์ตรง `products.html#solutions`)
- หน้าการศึกษา ความปลอดภัย และ AI Agent แสดงแถบเส้นทางเป็น "หน้าแรก / โซลูชันอื่น / …" (ชื่อแก้ที่ ⚙️ → ข้อความปุ่มและป้ายที่ใช้หลายหน้า)

## 6.7 ป๊อปอัพ โปรโมชั่น และขั้นตอนเริ่มใช้งาน 1-2-3

**ขั้นตอนเริ่มใช้งาน** แก้ที่ 📄 **หน้าเว็บ** → **หน้าแรก** → **5. ขั้นตอนเริ่มใช้งาน 1-2-3** ใช้ทั้งในหน้าแรกและในป๊อปอัพ (แก้ที่เดียวเปลี่ยนทั้งสองที่) แนะนำ 3 ขั้น ไม่เกิน 4 ขั้น · ถ้าเพิ่มหรือลดขั้น อย่าลืมแก้ตัวเลขในหัวข้อด้วย

**ป๊อปอัพ** แก้ที่เมนู 📣 **ป๊อปอัพ / โปรโมชั่น** มี 2 ส่วน

1. **ข้อความหลัก (แสดงตลอด):** รูป ป้ายเล็ก หัวข้อ รายละเอียด ขั้นตอน 1-2-3 และปุ่ม บอกลูกค้าว่าเราขายอะไร ให้ใคร **ไม่ต้องแก้ตอนลงโปรโมชั่น**
2. **🎁 โปรโมชั่น (ไม่ใส่ก็ได้):** ติ๊ก "แสดงโปรโมชั่น" ใส่วันที่เริ่ม–วันที่สิ้นสุด ป้ายเล็ก หัวข้อ และรายละเอียด/เงื่อนไข จะขึ้นเป็นกล่องเด่นใต้ข้อความหลัก เฉพาะช่วงวันที่ที่ตั้งไว้ (ตามเวลาประเทศไทย)
   - ใส่ **รูปช่วงโปรโมชั่น** ได้ (เช่น แบนเนอร์) จะแสดงแทนรูปปกติระหว่างโปร ถ้ารูปมีตัวหนังสือให้เลือก **"แสดงทั้งรูป"** รูปจะไม่ถูกตัด
   - ใส่ **ปุ่มหลักช่วงโปรโมชั่น** ได้ (เช่น "รับข้อเสนอนี้" → `contact.html?topic=quote`) จะแสดงแทนปุ่มหลักเดิมระหว่างโปร
   - พ้นวันสิ้นสุดแล้ว กล่องโปรโมชั่นหายไปเอง ป๊อปอัพกลับเป็นข้อความหลักตามเดิม ไม่ต้องกลับมาแก้ · ข้อความโปรที่พิมพ์ไว้ยังเก็บอยู่ แก้วันที่แล้วใช้ครั้งหน้าได้

ตั้งค่าอื่นๆ

- **เปิดใช้ป๊อปอัพ:** ติ๊ก = แสดง · ไม่ติ๊ก = ไม่แสดงเลย
- **แสดงที่หน้า:** หน้าแรกเท่านั้น (แนะนำ) หรือทุกหน้า (ไม่แสดงในหน้าติดต่อเราเสมอ)
- **แสดงหลังเปิดหน้าเว็บกี่วินาที:** แนะนำ 3 วินาที ให้ลูกค้าเห็นหน้าเว็บก่อน
- **ลูกค้าคนเดิมจะเห็นซ้ำหลังจากกี่วัน:** แนะนำ 7 วัน ลูกค้าจะได้ไม่รำคาญ · 0 = เห็นทุกครั้งที่เปิดเว็บใหม่
- **รูป:** แนวนอน ประมาณ 1600×700 px ไฟล์ไม่เกินประมาณ 300 KB
- ลูกค้าทุกคน (รวมคนที่เคยปิดไปแล้ว) จะเห็นป๊อปอัพอีกครั้ง 1 รอบ เมื่อ: แก้ข้อความหลัก รูป หรือขั้นตอน 1-2-3 · หรือเมื่อโปรโมชั่นใหม่เริ่ม
- ลูกค้าปิดได้ด้วยปุ่ม ✕ กดพื้นที่นอกกรอบ หรือปุ่ม Esc · บนมือถือป๊อปอัพจะขึ้นจากด้านล่างจอ และปุ่มอยู่ด้านล่างให้กดได้ตลอด

## 7. เปลี่ยนเบอร์โทร อีเมล หรือที่อยู่

⚙️ **ตั้งค่าทั้งเว็บไซต์** → **ข้อมูลบริษัทและช่องทางติดต่อ** แก้ครั้งเดียว ทุกที่เปลี่ยนตาม (ท้ายเว็บทุกหน้า หน้าติดต่อเรา และข้อความในแบบฟอร์ม)

## 8. แบบฟอร์มติดต่อ และการแจ้งเตือนเข้า Lark

📄 **หน้าเว็บ** → **ติดต่อเรา** → **3. แบบฟอร์ม**

- แก้ชื่อช่อง ข้อความยินยอม (PDPA) และปุ่มส่งได้
- **ตัวเลือก "เรื่องที่สนใจ":** แต่ละตัวเลือกกำหนด**อีโมจิ**และ**สีหัวการ์ด**ที่จะเด้งเข้ากลุ่ม Lark ของทีมขายได้
- **ตัวเลือก "รุ่นที่สนใจ":** เมื่อเพิ่มรถรุ่นใหม่ ให้เพิ่มที่นี่ด้วย
- ⚠️ **อย่าแก้ "รหัส" ของตัวเลือกเดิม** (demo, quote, buy, lease, …) เพราะปุ่มต่างๆ ในเว็บใช้รหัสนี้เลือกหัวข้อให้ลูกค้าอัตโนมัติ และรหัส buy / lease ใช้บันทึกวิธีจัดซื้อลง SALE CRM จะแก้ "ข้อความที่ลูกค้าเห็น" ได้ตามสบาย

หัวข้อ **4. ข้อความหลังกดส่งแบบฟอร์ม** ใช้แก้ข้อความขอบคุณและข้อความเมื่อส่งไม่สำเร็จ

ลิงก์ webhook ของ Lark เป็นข้อมูลลับ จึงไม่ได้อยู่ในหลังบ้าน ตั้งไว้ที่ Cloudflare → Workers & Pages → **superx-website** → Settings → Variables and Secrets (`LARK_WEBHOOK_URL`)

## 8.1 แชทบนเว็บ ตอบผ่าน Lark 💬

ลูกค้ากดปุ่ม **"แชทกับเรา"** มุมขวาล่าง (ทุกหน้า) → กรอกชื่อ เบอร์โทร และข้อความ → ขึ้นเป็น**การ์ดสีเขียว**ในกลุ่ม Lark "แชทจากเว็บไซต์"

**วิธีตอบลูกค้า (สำหรับพนักงาน)**
- กด **ตอบในเธรด (Reply in thread)** ของการ์ดลูกค้าคนนั้น ข้อความจะไปขึ้นในกล่องแชทของลูกค้าภายในไม่กี่วินาที (ลูกค้าเห็นชื่อผู้ตอบเป็น "ทีมงาน SuperX AI")
- ข้อความที่ลูกค้าพิมพ์เพิ่มจะเข้ามาในเธรดเดียวกัน
- พิมพ์ขึ้นต้นด้วย `//` = โน้ตคุยกันในทีม **ไม่ส่งถึงลูกค้า**
- ส่งได้เฉพาะข้อความตัวอักษร (รูปและไฟล์ยังส่งไม่ได้)
- ถ้าลูกค้าปิดเว็บไปแล้ว จะเห็นคำตอบเมื่อกลับมาเปิดเว็บด้วยเครื่องเดิม · ถ้าเรื่องด่วนให้โทรตามเบอร์บนการ์ด

**แก้ข้อความและเวลาทำการ:** เมนู 💬 **แชทบนเว็บ** (ข้อความต้อนรับ ช่องกรอก เวลาทำการ วันเสาร์/อาทิตย์) นอกเวลาทำการ กล่องแชทจะขึ้นจุดสีเหลืองและข้อความ "นอกเวลาทำการ ทิ้งข้อความไว้ได้"

### ตั้งค่าครั้งแรก (ผู้ดูแล Lark + ผู้ดูแล Cloudflare ทำครั้งเดียว)

ตอนนี้แชท**ปิดไว้** ทำตามลำดับนี้แล้วค่อยเปิด

1. **สร้างแอปใน Lark:** เข้า <https://open.larksuite.com/app> → **Create Custom App** ตั้งชื่อเช่น "SuperX Web Chat" (ถ้าบริษัทมีแอปที่ใช้กับ SALE CRM อยู่แล้ว ใช้แอปเดิมได้)
2. **เพิ่มความสามารถ Bot:** เมนู Add Features → **Bot**
3. **ขอสิทธิ์ (Permissions & Scopes)** ค้นหาแล้วเพิ่ม:
   - `im:message:send_as_bot` (ส่งข้อความในนามบอท)
   - `im:message.group_msg` (อ่านข้อความทั้งหมดในกลุ่มที่บอทอยู่ ใช้รับคำตอบของพนักงาน)
   - `im:message` และ `im:chat:readonly`
   - ถ้าตอนเพิ่ม Event ในข้อ 6 Lark บอกว่าต้องใช้สิทธิ์อื่นเพิ่ม ให้เพิ่มตามที่ขึ้น
4. **คัดลอกรหัส 3 ตัว:** Credentials → **App ID**, **App Secret** · Events & Callbacks → Encryption Strategy → **Verification Token** (ช่อง Encrypt Key เว้นว่างได้)
5. **ใส่รหัสใน Cloudflare:** Workers & Pages → **superx-website** → Settings → Variables and Secrets → Add แบบ **Secret**:
   `LARK_APP_ID`, `LARK_APP_SECRET`, `LARK_VERIFICATION_TOKEN` (ถ้าตั้ง Encrypt Key ไว้ ให้ใส่ `LARK_ENCRYPT_KEY` ด้วย) แล้วกด Deploy
6. **ตั้ง Event ใน Lark:** Events & Callbacks → Event Configuration → Request URL ใส่ `https://super-x.tech/api/chat/lark` (โดเมนจริงของเว็บ) → กด Verify ต้องขึ้นว่าสำเร็จ → Add Events: **Message received** (`im.message.receive_v1`) และ **Bot added to group** (`im.chat.member.bot.added_v1`)
7. **เผยแพร่แอป:** Version Management → Create Version → ส่งอนุมัติ ผู้ดูแล Lark ขององค์กรกดอนุมัติ
8. **สร้างกลุ่ม Lark ใหม่** ชื่อเช่น "แชทจากเว็บไซต์" ใส่ทีมขาย แล้ว**เพิ่มบอท**เข้ากลุ่ม (Settings → Bots → Add) บอทจะพิมพ์ว่า "✅ เชื่อมแชทจากเว็บไซต์กับกลุ่มนี้แล้ว" แปลว่าพร้อม
9. **เปิดแชท:** หลังบ้าน เมนู 💬 **แชทบนเว็บ** → ติ๊ก **"เปิดใช้แชทบนเว็บ"** → Save แล้วลองแชทจากมือถือตัวเองดู 1 ครั้ง

> ระบบใช้กลุ่มแรกที่เพิ่มบอทเข้าไป ถ้าต้องการย้ายไปกลุ่มอื่น ให้ใส่ chat_id ของกลุ่มใหม่ใน Cloudflare เป็น `LARK_CHAT_ID`
> บทสนทนาเก็บไว้ 90 วันบน Cloudflare แล้วลบเอง · ไม่มีค่าใช้จ่ายเพิ่มสำหรับจำนวนแชทระดับเว็บบริษัท (อยู่ในโควตาฟรีของ Cloudflare)

## 9. เพิ่มรถรุ่นใหม่

1. 🚐 **ข้อมูลรถแต่ละรุ่น** → เพิ่มรายการใหม่ → กรอกชื่อรุ่น รูปรถ (พื้นหลังโปร่งใส) ตัวเลขบนการ์ด สเปก และไฟล์ PDF
2. ให้รุ่นใหม่แสดงบนหน้าเว็บ: เปิดหัวข้อที่มีการ์ดรถหรือตารางสเปก (เช่น หน้าแรก → 4. รุ่นรถ RoboVan หรือหน้า RoboVan ทุกรุ่น) แล้วเพิ่มรุ่นในรายการ
3. เพิ่มในแบบฟอร์ม: ติดต่อเรา → 3. แบบฟอร์ม → ตัวเลือก "รุ่นที่สนใจ"
4. เพิ่มในเมนู (ถ้าต้องการ): ⚙️ → เมนูด้านบนและด้านล่างเว็บ → รายการในเมนูกลุ่มที่ 1 (RoboVan)

ชื่อแถวในตารางสเปก (เช่น "ความเร็วสูงสุด") แก้ที่ ⚙️ → **ตารางสเปกรถ**

## 10. ตรวจว่าเว็บอัปเดตแล้ว และถ้ามีปัญหา

- ดูสถานะที่ Cloudflare → Workers & Pages → **superx-website** → **Deployments**
  - ✅ สำเร็จ = เว็บอัปเดตแล้ว
  - ❌ ไม่สำเร็จ = เว็บ**ยังเป็นเวอร์ชันก่อนหน้า ไม่พัง** กดดู log แล้วส่งภาพหน้าจอให้ผู้ดูแล
- ทุกการกด Save ถูกเก็บประวัติไว้ใน GitHub (แท็บ Commits / History) ย้อนกลับไปเวอร์ชันก่อนได้เสมอ
- ถ้าแก้แล้วเว็บยังไม่เปลี่ยน: รอ 2 นาทีแล้วกด Refresh (หรือ Cmd + Shift + R)

## สำหรับผู้ดูแลระบบ

| ไฟล์ / โฟลเดอร์ | หน้าที่ |
|---|---|
| `content/` | เนื้อหาทั้งหมด (ไฟล์ JSON) หลังบ้านแก้ไฟล์ในนี้ |
| `assets/` | รูป วิดีโอ PDF CSS และ JavaScript |
| `build/` | ตัวสร้างหน้าเว็บ (Python ไม่ต้องติดตั้งอะไรเพิ่ม) และรายการช่องของหลังบ้าน |
| `worker.js` | ตัวรับแบบฟอร์มและส่งการ์ดเข้า Lark (และ SALE CRM ถ้าตั้งค่า) |
| `wrangler.jsonc` | ตั้งค่า Cloudflare: ก่อน deploy ทุกครั้งจะรัน `python3 build/build.py` แล้วนำโฟลเดอร์ `public/` ขึ้นเว็บ |
| `.pages.yml` | เมนูและช่องของหลังบ้าน (สร้างอัตโนมัติจาก `build/*.py` อย่าแก้ไฟล์นี้ตรงๆ) |
| `public/`, `worker-data.json` | ไฟล์ที่สร้างขึ้นตอน build (ไม่เก็บใน GitHub) |

คำสั่ง (ต้องมี Python 3 และ Node.js):

```sh
python3 build/build.py           # สร้างเว็บลง public/
python3 build/build.py --check   # ตรวจว่าไฟล์ใน content/ ตรงกับช่องของหลังบ้าน
python3 build/build.py --cms     # สร้าง .pages.yml ใหม่ หลังเพิ่มหรือแก้ช่องใน build/*.py (ต้องมี PyYAML)
npx wrangler dev                 # เปิดเว็บทดสอบในเครื่อง พร้อมตัวส่งแบบฟอร์ม
```

ค่าที่ตั้งใน Cloudflare (Settings → Variables and Secrets ประเภท Secret):
`LARK_WEBHOOK_URL` (จำเป็น), `LARK_WEBHOOK_SECRET`, `LARK_CRM_URL`,
`LARK_APP_ID` / `LARK_APP_SECRET` / `LARK_BASE_APP_TOKEN` / `LARK_BASE_TABLE_ID` (บันทึกลง SALE CRM), `LARK_API_BASE`
