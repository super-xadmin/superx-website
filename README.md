# เว็บไซต์ SUPERX AI — คู่มือแก้ไขเนื้อหาผ่านหลังบ้าน

เนื้อหาทุกอย่างบนเว็บ (ข้อความ 3 ภาษา รูป วิดีโอ PDF สเปกรถ ข่าว ผลงาน เมนู ข้อมูลติดต่อ แบบฟอร์ม) แก้ได้ที่หลังบ้าน **Pages CMS** โดยไม่ต้องเขียนโค้ด

**ขั้นตอนการทำงาน:** แก้ที่หลังบ้าน → กด **Save** → ระบบบันทึกเข้า GitHub → Cloudflare สร้างเว็บใหม่และขึ้นออนไลน์เองภายในประมาณ 1–2 นาที

---

## 1. เข้าหลังบ้าน

1. เปิด <https://app.pagescms.org>
2. เข้าสู่ระบบด้วยบัญชี GitHub ที่ดูแลเว็บ (super-xadmin)
3. เลือก **superx-website** แล้วเลือก branch **main**

> เชิญเพื่อนร่วมทีมมาช่วยแก้ได้ทางอีเมล (ไม่ต้องมีบัญชี GitHub) ที่หัวข้อ Collaborators ใน Pages CMS ผู้ที่ถูกเชิญแก้เนื้อหาและรูปได้ แต่แก้การตั้งค่าระบบไม่ได้

## 2. เมนูในหลังบ้าน

| เมนู | ใช้ทำอะไร |
|---|---|
| 📰 **ข่าวสาร** | เพิ่ม แก้ ซ่อน หรือลบข่าว |
| 📄 **หน้าเว็บ** | ทุกหน้าของเว็บ แต่ละหน้าแบ่งเป็นหัวข้อ เรียง 1, 2, 3… ตามที่เห็นบนเว็บจากบนลงล่าง |
| 📁 **ผลงาน / โครงการ** | โครงการในหน้า "ผลงาน" (1 โครงการ = 1 รายการ) |
| 🚐 **ข้อมูลรถแต่ละรุ่น** | ชื่อรุ่น รูปรถ สเปก ตัวเลขบนการ์ด ไฟล์ PDF ใช้ร่วมกันทุกหน้า แก้ที่เดียวเปลี่ยนทุกที่ |
| ⚙️ **ตั้งค่าทั้งเว็บไซต์** | ข้อมูลบริษัท (เบอร์ อีเมล ที่อยู่ โซเชียล โลโก้) เมนูด้านบน/ล่าง ข้อความปุ่มที่ใช้หลายหน้า และหัวแถวตารางสเปก |

ในทุกหน้าของเมนู 📄 จะมีหัวข้อ **"ตั้งค่าหน้า"** สำหรับชื่อหน้า (ที่แสดงบนแท็บและ Google) และแถบสีน้ำเงินท้ายหน้า

## 3. วิธีพิมพ์ข้อความ

- ข้อความทุกช่องมี 3 ภาษา: **· ไทย**, **· 中文**, **· English**
- ถ้าเว้นช่องจีนหรืออังกฤษว่าง เว็บจะแสดงภาษาอังกฤษ (หรือไทย) แทนให้อัตโนมัติ ไม่มีช่องว่างโผล่
- **ตัวหนา / คำเน้น:** พิมพ์ `**ข้อความ**` (ดอกจัน 2 ตัวหน้าและหลัง) ในย่อหน้าจะเป็นตัวหนา ส่วนในหัวข้อใหญ่จะเป็น**สีฟ้า**
- **ขึ้นบรรทัดใหม่:** กด Enter ในช่องข้อความแบบยาว
- **ลิงก์ในเว็บ:** ใส่ชื่อหน้า เช่น `contact.html`, `products.html#z20`, `contact.html?topic=demo`
- **ลิงก์ภายนอก:** ขึ้นต้นด้วย `https://`
- **รายการ (การ์ด ขั้นตอน รูป ฯลฯ):** เพิ่ม ลบ หรือสลับลำดับได้ในหลังบ้าน

## 4. รูปภาพ วิดีโอ และ PDF

- อัปโหลดได้ในช่องรูปหรือไฟล์ของแต่ละหัวข้อ หรือที่เมนู Media
- **รูป:** .webp หรือ .jpg ความกว้างประมาณ 1600–2000 px ขนาดไม่เกินประมาณ 1 MB ต่อรูป (เว็บจะโหลดเร็ว)
- **วิดีโอ:** .mp4 **ไม่เกิน 25 MB** (เป็นข้อจำกัดของ Cloudflare ไฟล์ที่ใหญ่กว่านี้จะไม่ถูกนำขึ้นเว็บ)
- **PDF:** ไม่เกิน 25 MB ขนาดไฟล์ที่แสดงบนปุ่มดาวน์โหลดคำนวณให้เอง
- ตั้งชื่อไฟล์เป็นภาษาอังกฤษ ไม่มีเว้นวรรค จะดีที่สุด เช่น `z10-factory-01.webp`
- ช่อง **"คำอธิบายรูป (alt)"** ใส่ภาษาอังกฤษสั้นๆ ว่าในรูปมีอะไร (ช่วยเรื่อง Google)

## 5. เพิ่มข่าวใหม่

1. เมนู 📰 **ข่าวสาร** → กดปุ่มเพิ่มรายการใหม่
2. กรอก **หัวข้อข่าว**, **วันที่ของข่าว**, **แสดงวันที่แบบ** (วัน เดือน ปี / เดือน ปี / ปีอย่างเดียว), **ประเภทข่าว**, **สรุปข่าวสั้นๆ** และ **รูปหลัก**
3. ถ้าต้องการให้มี**หน้าอ่านข่าวฉบับเต็ม** ให้พิมพ์ในช่อง **"เนื้อหาข่าวฉบับเต็ม"** (ใส่หัวข้อย่อย ตัวหนา รายการ ลิงก์ และรูปได้) เว็บจะสร้างหน้าใหม่ให้ และในรายการข่าวจะมีปุ่ม "อ่านข่าวฉบับเต็ม" ใส่รูปเพิ่มเติมหรือวิดีโอได้ด้วย
4. ถ้าเป็นข่าวที่สื่อลง ให้ใส่ **ลิงก์ข่าวต้นฉบับ** และ **ชื่อแหล่งข่าว**
5. ติ๊ก **"ข่าวเด่น"** ถ้าต้องการให้แสดงใหญ่ด้านบนสุดของหน้าข่าว (ถ้าติ๊กไว้หลายข่าว จะแสดงข่าวที่วันที่ใหม่ที่สุด)
6. กด **Save** แล้วรอ 1–2 นาที จากนั้นเปิดเว็บแล้วกด Refresh

ข่าวเรียงจากวันที่ใหม่ไปเก่าอัตโนมัติ · ถ้ายังไม่อยากให้ข่าวขึ้นเว็บ ให้ติ๊ก **"ซ่อนข่าวนี้"**

## 6. เพิ่มผลงาน / โครงการ

เมนู 📁 **ผลงาน / โครงการ** → เพิ่มรายการใหม่

- **รหัสโครงการ:** ภาษาอังกฤษตัวเล็ก ไม่เว้นวรรค เช่น `tpi-polene` ใช้ลิงก์ตรงไปที่โครงการได้ เช่น `cases.html#tpi-polene`
- **แสดงในส่วน:** "โครงการในประเทศไทย" (แบบละเอียด มีหลายรูป) หรือ "ภูมิภาคเอเชีย" (การ์ดเล็ก)
- **ลำดับการแสดง:** เลขน้อยแสดงก่อน
- รูปแรกในรายการรูปจะแสดงใหญ่ · มีวิดีโอได้ 1 คลิปต่อโครงการ

## 7. เปลี่ยนเบอร์โทร อีเมล หรือที่อยู่

⚙️ **ตั้งค่าทั้งเว็บไซต์** → **ข้อมูลบริษัทและช่องทางติดต่อ** แก้ครั้งเดียว ทุกที่เปลี่ยนตาม (ท้ายเว็บทุกหน้า หน้าติดต่อเรา และข้อความในแบบฟอร์ม)

## 8. แบบฟอร์มติดต่อ และการแจ้งเตือนเข้า Lark

📄 **หน้าเว็บ** → **ติดต่อเรา** → **3. แบบฟอร์ม**

- แก้ชื่อช่อง ข้อความยินยอม (PDPA) และปุ่มส่งได้
- **ตัวเลือก "เรื่องที่สนใจ":** แต่ละตัวเลือกกำหนด**อีโมจิ**และ**สีหัวการ์ด**ที่จะเด้งเข้ากลุ่ม Lark ของทีมขายได้
- **ตัวเลือก "รุ่นที่สนใจ":** เมื่อเพิ่มรถรุ่นใหม่ ให้เพิ่มที่นี่ด้วย
- ⚠️ **อย่าแก้ "รหัส" ของตัวเลือกเดิม** (demo, quote, buy, lease, …) เพราะปุ่มต่างๆ ในเว็บใช้รหัสนี้เลือกหัวข้อให้ลูกค้าอัตโนมัติ และรหัส buy / lease ใช้บันทึกวิธีจัดซื้อลง SALE CRM จะแก้ "ข้อความที่ลูกค้าเห็น" ได้ตามสบาย

หัวข้อ **4. ข้อความหลังกดส่งแบบฟอร์ม** ใช้แก้ข้อความขอบคุณและข้อความเมื่อส่งไม่สำเร็จ

ลิงก์ webhook ของ Lark เป็นข้อมูลลับ จึงไม่ได้อยู่ในหลังบ้าน ตั้งไว้ที่ Cloudflare → Workers & Pages → **superx-website** → Settings → Variables and Secrets (`LARK_WEBHOOK_URL`)

## 9. เพิ่มรถรุ่นใหม่

1. 🚐 **ข้อมูลรถแต่ละรุ่น** → เพิ่มรายการใหม่ → กรอกชื่อรุ่น รูปรถ (พื้นหลังโปร่งใส) ตัวเลขบนการ์ด สเปก และไฟล์ PDF
2. ให้รุ่นใหม่แสดงบนหน้าเว็บ: เปิดหัวข้อที่มีการ์ดรถหรือตารางสเปก (เช่น หน้าแรก → 4. รุ่นหลัก หรือหน้าผลิตภัณฑ์ทั้งหมด) แล้วเพิ่มรุ่นในรายการ
3. เพิ่มในแบบฟอร์ม: ติดต่อเรา → 3. แบบฟอร์ม → ตัวเลือก "รุ่นที่สนใจ"

ชื่อแถวในตารางสเปก (เช่น "ความเร็วสูงสุด") แก้ที่ ⚙️ → **ตารางสเปกรถ**

## 10. ตรวจว่าเว็บอัปเดตแล้ว และถ้ามีปัญหา

- ดูสถานะที่ Cloudflare → Workers & Pages → **superx-website** → **Deployments**
  - ✅ สำเร็จ = เว็บอัปเดตแล้ว
  - ❌ ไม่สำเร็จ = เว็บ**ยังเป็นเวอร์ชันก่อนหน้า ไม่พัง** กดดู log แล้วส่งภาพหน้าจอให้ผู้ดูแล
- ทุกการกด Save ถูกเก็บประวัติไว้ใน GitHub (แท็บ Commits / History) ย้อนกลับไปเวอร์ชันก่อนได้เสมอ
- ถ้าแก้แล้วเว็บยังไม่เปลี่ยน: รอ 2 นาทีแล้วกด Refresh (หรือ Cmd + Shift + R)

## สำหรับผู้ดูแลระบบ

| ไฟล์ / โฟลเดอร์ | หน้าที่ |
|---|---|
| `content/` | เนื้อหาทั้งหมด (ไฟล์ JSON) หลังบ้านแก้ไฟล์ในนี้ |
| `assets/` | รูป วิดีโอ PDF CSS และ JavaScript |
| `build/` | ตัวสร้างหน้าเว็บ (Python ไม่ต้องติดตั้งอะไรเพิ่ม) และรายการช่องของหลังบ้าน |
| `worker.js` | ตัวรับแบบฟอร์มและส่งการ์ดเข้า Lark (และ SALE CRM ถ้าตั้งค่า) |
| `wrangler.jsonc` | ตั้งค่า Cloudflare: ก่อน deploy ทุกครั้งจะรัน `python3 build/build.py` แล้วนำโฟลเดอร์ `public/` ขึ้นเว็บ |
| `.pages.yml` | เมนูและช่องของหลังบ้าน (สร้างอัตโนมัติจาก `build/*.py` อย่าแก้ไฟล์นี้ตรงๆ) |
| `public/`, `worker-data.json` | ไฟล์ที่สร้างขึ้นตอน build (ไม่เก็บใน GitHub) |

คำสั่ง (ต้องมี Python 3 และ Node.js):

```sh
python3 build/build.py           # สร้างเว็บลง public/
python3 build/build.py --check   # ตรวจว่าไฟล์ใน content/ ตรงกับช่องของหลังบ้าน
python3 build/build.py --cms     # สร้าง .pages.yml ใหม่ หลังเพิ่มหรือแก้ช่องใน build/*.py (ต้องมี PyYAML)
npx wrangler dev                 # เปิดเว็บทดสอบในเครื่อง พร้อมตัวส่งแบบฟอร์ม
```

ค่าที่ตั้งใน Cloudflare (Settings → Variables and Secrets ประเภท Secret):
`LARK_WEBHOOK_URL` (จำเป็น), `LARK_WEBHOOK_SECRET`, `LARK_CRM_URL`,
`LARK_APP_ID` / `LARK_APP_SECRET` / `LARK_BASE_APP_TOKEN` / `LARK_BASE_TABLE_ID` (บันทึกลง SALE CRM), `LARK_API_BASE`
